# FishBox｜钓鱼图鉴

一款基于 Kotlin 与 Jetpack Compose 的 Android 钓鱼图鉴和个人收集进度管理工具。提供鱼类资料查询、品质收集记录、条件筛选、收藏关注、进度统计，以及本地备份与恢复。

## 功能概览

### 图鉴与查找

- 收录 76 种鱼类资料。排序方式可在「设置」里切换：首字母（默认）、搏斗难度（可倒序，由难到易）、游戏内顺序（游戏图鉴的两个页签，固定每行 3 条）。
- 支持按中文名称、完整拼音和拼音首字母搜索。
- 提供 A–Z 字母快速定位。
- 鱼类详情展示描述、季节、时间、天气、地点、鱼竿类型、搏斗难度和各品质售价。
- 对部分鱼类提供专属品质名称及说明。

### 收集管理

- 每种鱼提供标准、非凡、稀有、史诗、传奇五档品质，可分别记录收集状态。
- 未集齐的鱼以灰度状态显示；五档全部收集后显示完整色彩。
- 支持关注鱼类，并可通过筛选快速查看关注列表。
- 支持单条鱼的全部收集或清空操作；重置等操作提供确认与撤销提示。

### 条件筛选

- 按收集状态筛选：已集齐、未集齐、已关注。
- 按游戏内的季节、时间、天气、地点、鱼竿和配件（轻型/重型）组合筛选。筛选面板第一行是鱼竿 + 配件，第二行是地点，之后依次是状态、季节、时间、天气，每类一行、可横向滑动。
- 同一类别内多个条件按“或”匹配，不同类别之间按“且”匹配。
- 配件即站点的"配件"分类，对应 `fish.json` 里的 `gear`（light / heavy）。
- 详情里的"鱼竿"：如果只有一把具体鱼竿能钓上来，就只显示那把鱼竿的名字，否则显示鱼竿类型。具体鱼竿数据见 `data/rods.json`（游戏里的 17 把鱼竿）和 `data/fish_rods.json`（每条鱼可用的具体鱼竿，由 `tools/fetch_fish_rods.bat` 从站点抓取生成；CI 构建时会自动运行；目前只预置了 3 条，缺数据的鱼回退显示鱼竿类型）。
- 鱼竿按出没地点判断：池塘、冰洞用池钓，其余地点用路亚（对应关系写在 `data/locations.json` 的 `rods` 字段，可按游戏实际修改；`fish.json` 里站点原始的 `rods` 保持不动）。
- 筛选面板像 Apple 的中等高度面板，只升到半屏，每个类别一行并可横向滑动；已选条件会以可逐个移除的芯片显示在列表顶部，随时可以增减。

### 统计与分享

- 查看总体品质收集进度和鱼类集齐数量。
- 按品质查看收集数量与完成情况。
- 找出只差一个品质即可集齐的鱼。
- 按季节和地点查看收集进度。
- 生成收集成果分享卡片。

### 备份与外观

- 将收集进度和关注列表导出为 JSON 文件。
- 从备份文件恢复前会校验数据，并要求用户确认；恢复操作支持撤销。
- 支持跟随系统、浅色和深色主题。
- Android 12 及以上支持动态取色选项。
- 支持紧凑、标准和大图三种鱼类卡片尺寸。
- 屏幕宽度达到 840dp 时，详情内容在右侧栏展示；较窄窗口使用底部详情面板。

## 设计与实现

项目采用单 Activity + Jetpack Compose 的界面结构，使用 Material 3 构建组件和主题。界面状态由 `CodexViewModel` 管理，并通过 `StateFlow` 向 Compose 界面提供数据。

当前工程是一个单模块应用，核心设计如下：

```
MainActivity
└── FishApp / FishCodexTheme
    └── CodexScreen
        ├── CodexContent       图鉴列表、搜索和字母定位
        ├── FilterSheet        条件筛选
        ├── FishSheet          手机端鱼类详情
        ├── DetailPane         大屏右侧详情栏
        ├── StatsSheet         收集统计
        └── Dialogs            外观、分享、备份恢复、关于等

CodexViewModel
├── fish.json                 静态鱼类资料
├── ProgressStore             SharedPreferences 收集进度与关注列表
└── SettingsStore             SharedPreferences 外观和应用设置
```
