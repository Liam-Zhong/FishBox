# FishBox｜钓鱼图鉴

一款基于 Kotlin 与 Jetpack Compose 的 Android 钓鱼图鉴。提供鱼类资料查询、品质收集记录、条件筛选、收藏关注、进度统计，以及本地备份与恢复。

## 功能概览

### 图鉴与查找

- 收录 76 种鱼类资料。
- 支持按中文名称、完整拼音和拼音首字母搜索。
- 提供 A–Z 字母快速定位。
- 鱼类详情展示描述、季节、时间、天气、地点、鱼竿类型、搏斗难度和各品质售价。

### 收集管理

- 每种鱼提供标准、非凡、稀有、史诗、传奇五档品质，可分别记录收集状态。
- 未集齐的鱼以灰度状态显示；五档全部收集后显示完整色彩。
- 支持关注鱼类，并可通过筛选快速查看关注列表。
- 支持单条鱼的全部收集或清空操作；重置等操作提供确认与撤销提示。

### 条件筛选

- 按收集状态筛选：已集齐、未集齐、已关注。
- 搜索：点顶栏的放大镜，顶栏变成搜索框（名称/拼音/首字母，实时生效），取消即恢复。
- 按游戏内的季节、时间、天气、地点、鱼竿和配件（轻型/重型）组合筛选。
- 同一类别内多个条件按“或”匹配，不同类别之间按“且”匹配。
- 详情里的"鱼竿"：如果只有一把具体鱼竿能钓上来，就只显示那把鱼竿的名字，否则显示鱼竿类型。具体鱼竿数据见 `data/rods.json`（游戏里的 17 把鱼竿）和 `data/fish_rods.json`（每条鱼可用的具体鱼竿，由 `tools/site_data.py rods`（或 `tools/fetch_fish_rods.bat`）从站点抓取生成；CI 构建前会自动运行 `site_data.py rods`，抓到不足 90% 的鱼时保留仓库里的旧文件；仓库里目前只预置了 3 条，缺数据的鱼回退显示鱼竿类型）。
- 鱼竿按出没地点判断：池塘、冰洞用池钓，其余地点用路亚。

### 统计与分享

- 查看总体品质收集进度和鱼类集齐数量。
- 按品质查看收集数量与完成情况。
- 找出只差一个品质即可集齐的鱼。
- 按季节和地点查看收集进度。
- 生成收集成果分享卡片。

## 设计与实现

项目采用单 Activity + Jetpack Compose 的界面结构，使用 Material 3 构建组件和主题。界面状态由 `CodexViewModel` 管理，并通过 `StateFlow` 向 Compose 界面提供数据。

当前工程是一个单模块应用，核心设计如下：

```
MainActivity
└── FishApp / FishCodexTheme
    └── CodexScreen
        ├── CodexContent       图鉴列表、搜索和字母定位
        ├── FilterSheet        条件筛选
        ├── FishSheet          手机端鱼类详情
        ├── DetailPane         大屏右侧详情栏
        ├── StatsSheet         收集统计
        └── Dialogs            外观、分享、备份恢复、关于等

CodexViewModel
├── fish.json                 静态鱼类资料
├── ProgressStore             SharedPreferences 收集进度与关注列表
└── SettingsStore             SharedPreferences 外观和应用设置
```
